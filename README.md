.---------------------------------------------------------.
Aurora CS Course Scheduler
.--------------------------------------------------------.
CSC3700 Advanced Web Application Development, Fall 2026, Prof. Lash.
.---------------------------------------------------------.
An app that displays the Aurora CS Developer Track course catalog, tracks which courses a student has completed, and shows which courses they are eligible to take next based on prerequisites.
.----------------------------------------------------------.




.----------------------------------------------------------.
                        How to run:
.---------------------------------------------------------.
1. Install dependencies: "npm install"
.---------------------------------------------------------.
2. Start JSON Server (leave this terminal open): "npm run server"
.---------------------------------------------------------.
3. Start the React app in a second terminal: "npm run dev"
.---------------------------------------------------------.
4. Open http://localhost:5173 in your browser.
-.--------------------------------------------------------.
